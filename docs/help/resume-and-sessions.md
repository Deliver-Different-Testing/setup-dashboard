A setup is a session saved on the server for the tenant, kept for 120 days from the last change. When you open the dashboard it reopens the setup you were last in on this browser; if there are others it asks which to resume or whether to start new. Anyone from the same tenant can open the same setup, so two people can share one.

Everything saved is there when you come back: step data, requests, checklist ticks, row results and training progress.

## Starting a second setup

Start new creates another session; useful for a trial run that you later delete. Rows created in Settings or Routed Operations by a deleted session are not removed; delete a setup only when its records are wanted or weren't sent.

## What isn't saved

Unsaved edits on the current step. Press Save (or Save & send) before closing the tab. Imports are saved automatically when loaded.

## Couriers' passwords

Never saved past the moment the courier is created. A resumed setup shows "set" against a courier whose login exists and never shows the password.
