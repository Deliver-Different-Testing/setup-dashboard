A vehicle size is the kind of vehicle a rate is priced for, such as Car, Van or 2-tonne truck. It needs only a name; weight capacity, pallet capacity, cubic capacity and a fuel percentage are optional. Every zone-to-zone rate and distance rate must name at least one vehicle size, so create the sizes first.

Sizes the tenant already has in Settings are listed on the step and can be used by name without recreating them.

## Naming

Use the name customers and dispatchers will see on bookings. Rates refer to vehicle sizes by this exact name, so decide it once.

## Fuel percent on a vehicle size

Optional, typed as a percentage. It is separate from fuel surcharges, which are dated and can be per customer.
