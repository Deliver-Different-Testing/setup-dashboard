Carriers, Shopify stores, partner links and other connections are made in Integration Manager, which the step links to. The dashboard doesn't create integrations; tick "Integrations the tenant needs are connected" when each is done. The item is required for the step to be marked done, so if the tenant needs none, tick it anyway and note that in the request list.

## What to connect first

Accounting (so invoices sync from the first invoice run) and any carrier the tenant hands overflow to. Shopify and API keys can wait until the tenant has a customer asking for them.
