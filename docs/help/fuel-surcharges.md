A fuel surcharge needs a percentage and a start date. Name is optional (one is made from the percent and date if blank), and a customer code is optional: blank means the surcharge applies generally; a code restricts it to that one customer, who must have been created on the Customers step. Type the percentage as a percentage (10 means 10 %); it is converted for Settings.

## One customer per surcharge

Settings fuel surcharges carry a single optional customer. For a surcharge that applies to several named customers, create one row per customer.

## Changing it later

Fuel surcharges are dated, so a new rate from a new date is a new row, not an edit. After setup they live in Settings > Rates & Pricing.
