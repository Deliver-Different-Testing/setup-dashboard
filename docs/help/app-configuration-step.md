App configuration is done on Settings > Admin Setup screens and tracked here as three checklist items with links: Admin Setup catalogues (note types, document types, quizzes), dispatch settings and the sign-up page, and consumer or baggage delivery settings if the tenant uses them. None are required, so the step can be marked done with any of them unticked. Tick each as the tenant finishes it.

## Order

Catalogues first (note and document types are used by the driver app from the first job), then dispatch settings, then the sign-up page if customers will self-register.
