Automation rules (notifications on status changes, auto-assign and the like) are built in Settings > Automations, not on the dashboard, because they use the tenant's own job statuses and message templates, and because a rule goes live the moment it is saved there. The step is a checklist with a link: set the rules up once rates and schedules are in, then tick "Automation rules set up" here.

It is a required item, so the step can't be marked done without it.

## Suggested first rules

A notification to the customer at pickup and at delivery, a proof-of-delivery email, and a late-running alert to dispatch. Keep the daily summary off until the tenant asks.

## Rules go live on save

Build and test rules before couriers are live, or with a test customer, because there is no draft state in Settings.
